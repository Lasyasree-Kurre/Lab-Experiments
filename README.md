# 💻 C Programming Lab

A collection of C programs organized by weekly lab experiments.

## 📚 Weekly Breakdown

### 📁 Week 1 — Basic Input & Output
- Using `printf()` and `scanf()`.

### 📁 Week 2 — Basic Calculations
- Sum and average of three numbers.
- Temperature conversion (Fahrenheit ↔ Celsius).
- Simple interest calculation.

### 📁 Week 3 — Mathematical Programs
- Square root of a number.
- Compound interest calculation.
- Area of a triangle using Heron's formula.
- Distance travelled by an object.

### 📁 Week 4 — Operators & Expressions
- Evaluation of arithmetic and increment/decrement expressions.
- Maximum of three numbers using the conditional operator.
- Total and average marks of five subjects.

### 📁 Week 5 — Decision-Making & Control Statements
- Maximum and minimum of four numbers using `if-else`.
- Household electricity bill calculation.
- Roots of a quadratic equation.
- Menu-driven calculator using `switch`.
- Leap year verification.
